## Search File Order
https://docs.splunk.com/Documentation/Splunk/latest/Knowledge/Searchtimeoperationssequence
| Search-time operation order | Operation name                               | Configurable in Splunk Web? | Location of file configuration                                                                                                                                                                                                                      |
| --------------------------- | -------------------------------------------- | --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1                           | Inline field extraction (no field transform) | Yes                         | `EXTRACT-<class>` in a stanza in the [props.conf](http://docs.splunk.com/Documentation/Splunk/9.4.1/Admin/Propsconf) file.                                                                                                                          |
| 2                           | Field extraction that uses a field transform | Yes                         | `REPORT-<class>` in a stanza in the [props.conf](http://docs.splunk.com/Documentation/Splunk/9.4.1/Admin/Propsconf) file.                                                                                                                           |
| 3                           | Automatic key-value field extraction         | No                          | In stanzas in the [props.conf](http://docs.splunk.com/Documentation/Splunk/9.4.1/Admin/Propsconf) file, where `KV_MODE` is set to a valid value other than `none`. If no `KV_MODE` value is specified for a stanza, it is set to `auto` by default. |
| 4                           | Field filters                                | Yes                         | `fieldFilterName` stanza in the [field_filters.conf](http://docs.splunk.com/Documentation/Splunk/9.4.1/Admin/Fieldfiltersconf) file.                                                                                                                |
| 5                           | Field aliasing                               | Yes                         | `FIELDALIAS-<class>` in a stanza in the [props.conf](http://docs.splunk.com/Documentation/Splunk/9.4.1/Admin/Propsconf) file.                                                                                                                       |
| 6                           | Calculated fields                            | Yes                         | `EVAL-<fieldname>` in a stanza in the [props.conf](http://docs.splunk.com/Documentation/Splunk/9.4.1/Admin/Propsconf) file.                                                                                                                         |
| 7                           | Lookups                                      | Yes                         | `LOOKUP-<class>` in a stanza in the [props.conf](http://docs.splunk.com/Documentation/Splunk/9.4.1/Admin/Propsconf) file.                                                                                                                           |
| 8                           | Event types                                  | Yes                         | In a stanza in the [eventtypes.conf](http://docs.splunk.com/Documentation/Splunk/9.4.1/Admin/Eventtypesconf) file.                                                                                                                                  |
| 9                           | Tags                                         | Yes                         | In a stanza in the [tags.conf](http://docs.splunk.com/Documentation/Splunk/9.4.1/Admin/Tagsconf) file.                                                                                                                                              |
