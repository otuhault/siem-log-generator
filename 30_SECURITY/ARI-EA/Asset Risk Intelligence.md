### ARI is
- security investigation tool designed to enrich data for assets and accounts
- supports SEOps (Security Operations) teams in gaining better visibility into assets
- falls under the IT risk management product category
- enhances existing IT operations and asset inventory tools rather than replacing them
- integrates seamlessly with ES and Service Now CMDB to improve asset visibility and context
### ARI is not
- an asset management tool
- a Configuration Management Database (CMDB) or replacement for one
### Key Capabilities
- leverages existing data sources within Splunk
- correlates, analyses, enriches asset data using customisable pattern matching rules
- automatically discovers assets like endpoints, servers, users, OT, IoT, devices
- builds comprehensive, continuously updated asset inventories
- correlates data across multiple sources to provide a single, enriched view per asset
- identifies and tracks IPs, MAC addresses, software versions, users, and vulnerabilities
- helps measure endpoint compliance, track asset activity, identify asset relationships, and enrich other systems
- reduces manual effort by deduplicating asset information automatically
- provides enhanced visibility into unknown or unmanaged assets
- improves investigation efficacy by linking alert data to accurate asset and identity information
### Integration
- integrates with ES and ServiceNow
- supports enriching CMDB accurate and complete asset data
- helps customers using ServiceNow leverage existing CMDB data by enhancing it rather than replacing it
- works in tandem with Exposure Analytics and ES for enhance capabilities
