# Splunk Enterprise Security 8.7 (8.7.0 & 8.7.1)

> [!summary] Executive Summary

> **Splunk Enterprise Security 8.7** accelerates the transition to the **Agentic SOC**, delivering production AI-driven workflows across the incident lifecycle. The **8.7.1 maintenance release** (October 1, 2026) expands autonomous triage with the **Connector Builder Agent**, enhanced **Automation Builder Agent**, full **Enterprise Security context on Mission Control (MCP)**, and context-aware **AI SOC Analyst** response guidance.

### 1. 🤖 The Agentic SOC: Specialized AI Agents (8.7.0 & 8.7.1)
* ****Connector Builder Agent (New in 8.7.1):**** AI-generated, automated SOAR/ES connector building and testing from natural language specs.
* ****AI SOC Analyst (Enhanced in 8.7.1):**** Machine-speed triage and response plan execution with strict Human-In-The-Loop (HITL) guardrails.
* ****Automation Builder Agent (Enhanced in 8.7.1):**** Context-aware playbook tuning leveraging active finding sessions.
* ****Detection Builder Agent (8.7.0):**** MITRE ATT&CK aligned correlation search and RBA rule generator.
  
### 2. ⚡ UI, Navigation & Operational Visibility
* ****Mission Control (MCP) Integration:**** Direct injection of findings, entity risk factors, and assets/identities into agent reasoning context.
* ****Revamped Navigation & Team Queues:**** Customizable navigation, analyst saved views, and team-based queue routing.
* ****View Change History:**** Native audit timeline of changes made to detections and suppression rules.

### 3. ⚠️ Installation, Architecture & Upgrade Guardrails

> [!danger] On-Premises Installation on Splunk Core 10.x

> Uploading ES 8.x via Splunk Web UI is disabled on Splunk Enterprise 10.x. Installation/update must be performed strictly via CLI:

> `splunk install app /tmp/splunk-enterprise-security_871.spl -update 1 -auth admin:<password>`

> [!warning] Navigation XML Customizations

> Upgrading resets default navigation layouts. Backup `default.xml` in `$SPLUNK_HOME/etc/apps/SplunkEnterpriseSecuritySuite/local/data/ui/nav/` prior to upgrade.
